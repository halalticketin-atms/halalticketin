Halal Ticketin' Embed Widget

Display your events on any website with a simple embed code

Quick Start

Add the following code to your website where you want events to appear:

<!-- Event container -->
<div id="halal-ticketin-events"></div>

<!-- Embed script -->
<script src="https://yoursite.com/embed/events.js"></script>

Configuration Options

Attribute Description Default
data-organizer-id Filter events to a specific organizer (UUID) All organizers
data-limit Maximum number of events to display 6
data-theme Color theme: light or dark light

Example with Options

<div id="halal-ticketin-events"
     data-organizer-id="your-organizer-uuid"
     data-limit="3"
     data-theme="dark">
</div>
<script src="/embed/events.js"></script>

JavaScript API

You can programmatically refresh the widget:

// Refresh the embed with latest events
window.HalalTicketinEmbed.refresh();
